# 🧠 **EmoDrift**

## **Temporal Emotion Drift Detection using NLP**

EmoDrift is a Natural Language Processing (NLP) project designed to analyze **emotional trends and mood shifts over time** from textual data. Unlike traditional sentiment analysis that evaluates text individually, EmoDrift focuses on **collective emotional behavior**, enabling the detection of gradual or sudden emotional changes (emotion drift).

This project is suitable for **college mini/major projects**, **PEP selections**, and **AI/ML expos** due to its structured pipeline and unique problem focus.

---

## 🎯 **Project Objective**

* To move beyond single-text sentiment classification
* To analyze **how emotions evolve over time**
* To detect **temporal emotion drift**
* To visualize long-term emotional trends clearly
* To extract meaningful insights from emotional patterns

---

## ❓ **Problem Statement**

Traditional sentiment analysis systems classify emotions at an **individual level** (positive, negative, neutral).
However, they fail to:

* Capture **temporal emotion changes**
* Detect **collective mood shifts**
* Understand long-term emotional patterns

**EmoDrift solves this problem** by introducing time-aware sentiment aggregation and drift detection.


   ```bash

   ```

4. Run all cells sequentially to view analysis and visualizations.
